副檔名 .md 是 Markdown 格式的純文字檔案。
它是一種輕量級的標記語言，透過在純文字中加入簡單的符號（例如用 # 代表標題、** 代表粗體）來進行排版與格式化，無須使用複雜的網頁程式碼或排版軟體。

主要特點與用途

高易讀性：即使不透過專用軟體渲染成排版畫面，直接閱讀 .md 檔案的原始純文字也十分直覺易懂。
常見應用場景：最常作為開源軟體專案的說明文件（如 GitHub 上的 README.md）、技術文件撰寫，以及現代筆記與知識管理軟體（如 Obsidian、Notion、HackMD）的底層或匯出格式。

如何開啟與編輯
基礎文字編輯器：因為本質是純文字，您可以使用 Windows 內建的「記事本」或 macOS 的「文字編輯」直接打開。
支援預覽的專用編輯器：如果您希望一邊編寫一邊看到排版後的精美畫面，建議使用 Typora、Visual Studio Code（搭配外掛）、Sublime Text 或線上編輯器（如 HackMD）。
